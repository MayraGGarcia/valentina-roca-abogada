# Valentina Roca — Abogada ⚖️

Landing page de portfolio para un estudio jurídico boutique ficticio, especializado en derecho de familia y sucesiones.

🔗 **Ver demo en vivo:** https://mayraggarcia.github.io/valentina-roca-abogada/

## 🛒 Esta plantilla está a la venta
Disponible como producto digital listo para personalizar: [[link de Payhip]](https://payhip.com/b/x4lK5)

## Sobre el proyecto
Pensada para transmitir seriedad profesional sin perder cercanía. La identidad usa un isotipo de dos anillos entrelazados en vez de la iconografía típica de balanza o martillo.

## Stack
- HTML5
- CSS3 (variables, grid)
- JavaScript vanilla (scroll reveal, menú responsive)
- Google Fonts (Cormorant Garamond, Inter)

## Características
- Diseño 100% responsive
- Sección de "primera consulta" con proceso paso a paso
- Testimonio y estadísticas de trayectoria

---
Proyecto de portfolio — no corresponde a un estudio jurídico real.
